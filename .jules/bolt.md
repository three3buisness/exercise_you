## 2026-07-19 - CRLF Line Endings and UTF-8 Meta Tag Optimizations
**Learning:** Working with static HTML files that have CRLF line terminators (like `exercise.html` in this repo) can cause automated search-and-replace tools like `replace_with_git_merge_diff` to fail or produce excessive noise in Git diffs. Temporarily converting CRLF to LF line endings before performing edits, applying changes, and then restoring CRLF line endings resolves compatibility and formatting issues completely. Additionally, declaring `<meta charset="UTF-8">` early in the `<head>` block is a highly effective, low-risk way to prevent browsers from parsing delays related to guessing character encodings, especially when incorporating non-ASCII characters like "⚡".
**Action:** When working on HTML files in this repository, always inspect line terminators with the `file` command first. If CRLF is used, convert to LF before editing and restore to CRLF after editing. Always use `<meta charset="UTF-8">` as one of the first tags in `<head>` to maintain parsing speed and prevent charset shift detection overhead.

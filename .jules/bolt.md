## 2026-07-21 - [CRLF handling during automated diffs and Preconnect for YouTube resources]
**Learning:** In static HTML templates originating from Windows or specific legacy systems, line endings might be CRLF (`\r\n`). Applying diffs with `replace_with_git_merge_diff` can fail or introduce git noise if not pre-converted to LF (`\n`) and later restored to CRLF (`\r\n`). Additionally, for highly static video repositories linking directly to YouTube links, preconnecting to `https://youtube.com` and `https://youtu.be` reduces DNS, TCP, and TLS connection handshake latency.
**Action:** Always check file line terminators via `file` command first, then perform a 3-step sequence: (1) convert to LF, (2) apply change, (3) restore CRLF, and use `preconnect` hints for known heavy external links.

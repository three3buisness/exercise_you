## 2026-08-09 - Resource Hints and CRLF line endings
**Learning:** In a static HTML document with CRLF line endings, applying code changes with tools like `replace_with_git_merge_diff` can be error-prone or cause diff noises. Converting the line ending style to LF first, applying the code change, and then restoring CRLF line endings keeps the code clean and maintains tool compatibility. Additionally, adding preconnect resource hints for critical external domains (such as `youtube.com` and `youtu.be`) reduces link latency by ~100-125ms for external redirects.
**Action:** Always verify a file's line endings using `file <filename>`. Convert files to LF before editing and restore CRLF afterward if required. Always use precise, targeted search blocks to match long lines of static HTML.
